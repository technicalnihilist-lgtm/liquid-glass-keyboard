Liquid Glass Keyboard

A real Android keyboard with a glassy, colour-shifting keypad. Fully offline — no internet permission at all.

Download

Download the APK Source on GitHub

What it does

  • Full QWERTY with shift, double-tap caps lock and sentence capitals
  • Numbers, symbols and emoji pages; long-press accents on 16 letters
  • Repeating backspace that clears selections and steps over whole emoji
  • A return key that reads the field: send, search, go, next, done
  • Dark glass, light glass, or follow the system; three key heights
  • Real backdrop blur on Android 12+; layered specular glass everywhere

What it does not do

  • No predictive text, no autocorrect, no swipe typing
  • No clipboard history, no accounts, no ads, no analytics
  • No internet permission — it cannot reach the network
